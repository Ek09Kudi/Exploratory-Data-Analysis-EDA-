# Exploratory Data Analysis (EDA)

## Project Overview

Exploratory Data Analysis (EDA) is an important step in the Data Science and Machine Learning workflow. It involves analysing datasets to understand their structure, identify patterns, detect anomalies, handle missing values, and discover relationships between variables.

This project demonstrates the process of performing EDA using Python in Jupyter Notebook, with the help of popular data analysis and visualisation libraries.

## Objectives

- Understand the structure and characteristics of the dataset.
- Identify and handle missing values.
- Identify outliers and unusual observations.
- Visualise data distributions and patterns.


## Technologies & Libraries Used

| Technology | Purpose |
|---|---|
| Python | Programming language |
| Jupyter Notebook | Interactive development environment |
| Pandas | Data manipulation and analysis |
| NumPy | Numerical operations |
| Matplotlib | Data visualisation |
| Seaborn | Statistical data visualisation |
